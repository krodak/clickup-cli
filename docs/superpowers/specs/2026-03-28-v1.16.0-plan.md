### Config changes (`src/config.ts`)


- `getFilters(profileName?: string): FiltersMap` — loads filters for the active (or named) profile
- `saveFilter(name: string, entry: FilterEntry, profileName?: string): void` — writes filter to profile

## Task 4: `cup time list` defaults to current user

### What to build

Change `cup time list` to default to the authenticated user's entries. Add `--all` flag.

### Changes

**`src/commands/time.ts`:**

```ts
export async function listTimeEntries(
  config: Config,
  opts?: {
    days?: number
    taskId?: string
    spaceId?: string
    listId?: string
    assigneeId?: string
    all?: boolean // NEW
  },
): Promise<TimeEntry[]> {
  const client = new ClickUpClient(config)
  const days = opts?.days ?? 7
  const endDate = Date.now()
  const startDate = endDate - days * 24 * 60 * 60 * 1000

  let assigneeId = opts?.assigneeId
  if (!opts?.all && !assigneeId) {
    const me = await client.getMe()
    assigneeId = String(me.id)
  }

  return client.getTimeEntries(config.teamId, {
    startDate,
    endDate,
    taskId: opts?.taskId,
    spaceId: opts?.spaceId,
    listId: opts?.listId,
    assigneeId,
  })
}
```

## Task 5: `cup list-create --copy-statuses-from`

### What to build

Add `--copy-statuses-from <id>` flag to `cup list-create`. Fetches statuses from a source list or space, creates the new list, then applies the status set.

### API additions (`src/api.ts`)

```ts
// Fetch list with statuses (reuse existing getListWithStatuses)
// Already exists: getListWithStatuses(listId): Promise<ListWithStatuses>

// New: get space statuses
async getSpace(spaceId: string): Promise<{ id: string; name: string; statuses: Array<{ status: string; color: string; type: string }> }>

// New: update list (for setting statuses after creation)
async updateList(
  listId: string,
  payload: { statuses?: Array<{ status: string; color: string; type: string }> }
): Promise<{ id: string; name: string }>
```

### Command logic

```ts
// src/commands/list-create.ts (new file, or inline in index.ts)
async function copyStatusesFrom(
  client: ClickUpClient,
  sourceId: string,
): Promise<Array<{ status: string; color: string; type: string }>>
```

Try `client.getListWithStatuses(sourceId)` first. If it throws/returns null, try `client.getSpace(sourceId)`. Extract the `statuses` array.

After creating the list via `client.createList(spaceId, name)` (or `createFolderList`), call `client.updateList(newListId, { statuses })`.

### Registration in `src/index.ts`

Find the `list-create` command and add:

```
.option('--copy-statuses-from <id>', 'Copy status set from a list or space ID')
```

In the action handler, if `--copy-statuses-from` given, call `copyStatusesFrom` and then `updateList`.

### Tests (`tests/unit/commands/list-create.test.ts`)

New test file:

- Creates list without `--copy-statuses-from`: calls `createList`, no `updateList`
- With `--copy-statuses-from <listId>`: calls `getListWithStatuses`, then `createList`, then `updateList` with statuses
- With `--copy-statuses-from <spaceId>` (list fetch fails): calls `getSpace`, then `createList`, then `updateList`
- Source not found (both fetch attempts fail): throws informative error

### Metadata/docs/completions
